Floating-Point Extensions

The F, D, Q, Zfh, Zfhmin, Zfbfmin, and Zfa suites use floating-point registers. The Zfinx, Zdinx, Zhinx, and Zhinxmin suites use integer registers and do not require F. The coverpoints are specified in the following sections. Some tests only apply when multiple extensions are supported.

The basic coverpoints are defined in Coverpoints. Modified coverpoints for floating-point instructions are defined in Floating-Point Modified Coverpoint Definitions. D, H, and Q suffixes select double-, half-, and quad-precision operands, respectively.

fsgnj-s_fsgnjn-s_fsgnjx-s_op

FSGNJ.S, FSGNJN.S, and FSGNJX.S are floating-point to floating-point sign-injection instructions that produce a result that takes all bits except the sign bit from rs1. For FSGNJ, the result’s sign bit is rs2’s sign bit; for FSGNJN, the result’s sign bit is the opposite of rs2’s sign bit; and for FSGNJX, the sign bit is the XOR of the sign bits of rs1 and rs2. Sign-injection instructions do not set floating-point exception flags, nor do they canonicalize NaNs

{F_fsgnj_s_cg, F_fsgnjn_s_cg, F_fsgnjx_s_cg}/cr_fs1_fs2_edges

fmv-x-w_op

FMV.X.W moves the single-precision value in floating-point register rs1 represented in the IEEE 754-2008 encoding to the lower 32 bits of integer register rd. The bits are not modified in the transfer, and in particular, the payloads of non-canonical NaNs are preserved. For RV64, the higher 32 bits of the destination register are filled with copies of the floating-point number’s sign bit

F_fmv_x_w_cg/{cp_rd, cp_fs1, cp_fs1_edges}

fmv-w-x_op

FMV.W.X moves the single-precision value encoded in the IEEE 754-2008 encoding from the lower 32 bits of integer register rs1 to the floating-point register rd. The bits are not modified in the transfer, and in particular, the payloads of non-canonical NaNs are preserved.

F_fmv_w_x_cg/{cp_rs1, cp_rs1_edges, cp_fd}

feq-s_flt-s_fle-s_op

Floating-point compare instructions (FEQ.S, FLT.S, FLE.S) perform the specified comparison between floating-point registers (rs1 = rs2, rs1 < rs2, rs1 ≤ rs2) writing 1 to the integer register rd if the condition holds, and 0 otherwise.

{F_feq_s_cg, F_flt_s_cg, F_fle_s_cg}/cr_fs1_fs2_edges

flt-s_fle-s_signaling

FLT.S and FLE.S perform what IEEE 754-2008 refers to as signaling comparisons: that is, they set the invalid operation exception flag if either input is NaN

{F_fle_s_cg, F_flt_s_cg}/{cr_fs1_fs2_edges, cp_csr_fflags_v}

feq-s_quiet

FEQ.S performs a quiet comparison: it only sets the invalid operation exception flag if either input is a signaling NaN

F_feq_s_cg/{cr_fs1_fs2_edges, cp_csr_fflags_v}

feq-s_flt-s_fle-s_nan_input

For all three instructions, the result is 0 if either operand is NaN

{F_feq_s_cg, F_fle_s_cg, F_flt_s_cg}/cr_fs1_fs2_edges

fclass-s_op

The FCLASS.S instruction examines the value in floating-point register rs1 and writes to integer register rd a 10-bit mask that indicates the class of the floating-point number. The format of the mask is described in norm:fclass_result_enc. The corresponding bit in rd will be set if the property is true and clear otherwise. All other bits in rd are cleared. Note that exactly one bit in rd will be set. FCLASS.S does not set the floating-point exception flags.

When multiple floating-point precisions are supported, then valid values of narrower n-bit types, n<FLEN, are represented in the lower n bits of an FLEN-bit NaN value, in a process termed NaN-boxing.
