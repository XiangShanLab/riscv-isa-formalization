# VFMACC, VFNMACC, VFMSAC, VFNMSAC — vector floating-point fused multiply-accumulate

The four instructions multiply `vs1` and `vs2` and accumulate into the destination element, which is
also the addend (Unpriv. §31.13.6, `sources/riscv-unprivileged.txt:18400-18460`). They are
destructive: the old value of `vd` is an operand. Write `op` for the mnemonic, so that
`instr=VF_op.form` with `op∈{MACC,NMACC,MSAC,NMSAC}`; the element equations are

| `op` | `f(i)` |
|---|---|
| `MACC` | $\mathrm{fma}_{\mathrm{SEW}}(a_i,b_i,c_i)$ |
| `NMACC` | $\mathrm{fma}_{\mathrm{SEW}}(\mathrm{neg}(a_i),b_i,\mathrm{neg}(c_i))$ |
| `MSAC` | $\mathrm{fma}_{\mathrm{SEW}}(a_i,b_i,\mathrm{neg}(c_i))$ |
| `NMSAC` | $\mathrm{fma}_{\mathrm{SEW}}(\mathrm{neg}(a_i),b_i,c_i)$ |

Here `a_i` is element `i` of `vs1`, `b_i` is element `i` of `vs2` for `.vv` or
$\mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])$ for `.vf`, and `c_i` is the old element `i` of `vd`. The
`neg` in the table is the bit-level sign flip of §7.1. The single rounding is that of `fma`, and
its flags are those of §7.3; the destination group is read before it is written.

**(VFMACC.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{op}\in\{\mathrm{MACC},\mathrm{NMACC},\mathrm{MSAC},\mathrm{NMSAC}\})\\
&\land\ (\mathrm{form}\in\{\mathrm{VV},\mathrm{VF}\})\\
&\land\ (\mathrm{instr}=\mathrm{VF}_{\mathrm{op}}.\mathrm{form})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$
