# VFSLIDE1DOWN.VF — vector floating-point slide-1-down

`VFSLIDE1DOWN.VF` shifts the active elements of `vs2` down by one index and places the scalar
`f[rs1]` in element `vl-1`: element `i` receives `vs2[i+1]` for `vstart\le i<vl-1`, and element
`vl-1` receives the scalar (Unpriv. §31.16.3.6, `sources/riscv-unprivileged.txt:20188-20220`). The
instruction is masked and the tail follows `vta`; if `vstart\ge vl` the destination is unchanged.
The destination group must not overlap the source group; other overlaps are reserved (§4.5).

With `a_i` element `i` of `vs2`, the per-element result is $f(i)=a_{i+1}$ for `i<vl-1` and
$f(i)=\mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])$ for `i=vl-1`. No flag is raised and no `f` register is
written.

**(VFSLIDE1DOWN.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{instr}=\mathrm{VFSLIDE1DOWN}.\mathrm{VF})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$

&\land\ fcsr.frm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\}\\
&\land\ \mathrm{SEW}\in\{16,32,64\}\\
&\land\ \mathrm{instr}=\mathrm{VFSLIDE1DOWN}.\mathrm{VF}
\end{aligned}
\longrightarrow
\{\, \mathrm{Im}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vd)=\mathrm{Out}_{\mathrm{SEW},\mathrm{LMUL}}(\mathrm{Im}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vd),\lambda i.\bigl(i=vl-1\ ?\ \mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])\ :\ \mathrm{el}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vs2,i+1)\bigr),vl,vstart,\mathrm{vm},\mathrm{V}_0,vta,vma),\ vstart=0,\ mstatus.VS=\mathrm{Dirty}(3),\ \mathrm{exception}=\varnothing \,\}
