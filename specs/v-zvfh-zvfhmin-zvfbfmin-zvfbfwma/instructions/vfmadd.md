# VFMADD, VFNMADD, VFMSUB, VFNMSUB — vector floating-point fused multiply-add

The four instructions multiply `vs1` by the destination element and add `vs2`, that is, they use
`vs1` as the first multiplicand, the old `vd` as the second multiplicand, and `vs2` as the addend
(Unpriv. §31.13.6, `sources/riscv-unprivileged.txt:18400-18460`). Write `op∈{MADD,NMADD,MSUB,NMSUB}`
for the mnemonic, so that `instr=VF_op.form`; the element equations are

| `op` | `f(i)` |
|---|---|
| `MADD` | $\mathrm{fma}_{\mathrm{SEW}}(a_i,c_i,b_i)$ |
| `NMADD` | $\mathrm{fma}_{\mathrm{SEW}}(\mathrm{neg}(a_i),c_i,\mathrm{neg}(b_i))$ |
| `MSUB` | $\mathrm{fma}_{\mathrm{SEW}}(a_i,c_i,\mathrm{neg}(b_i))$ |
| `NMSUB` | $\mathrm{fma}_{\mathrm{SEW}}(\mathrm{neg}(a_i),c_i,b_i)$ |

Here `a_i` is element `i` of `vs1`, `b_i` is element `i` of `vs2` for `.vv` or
$\mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])$ for `.vf`, and `c_i` is the old element `i` of `vd`. The
destination group is read before it is written, and the flags are those of the single `fma`
rounding.

**(VFMADD.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{op}\in\{\mathrm{MADD},\mathrm{NMADD},\mathrm{MSUB},\mathrm{NMSUB}\})\\
&\land\ (\mathrm{form}\in\{\mathrm{VV},\mathrm{VF}\})\\
&\land\ (\mathrm{instr}=\mathrm{VF}_{\mathrm{op}}.\mathrm{form})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$

&\land\ \mathrm{instr}=\mathrm{VF}_{\mathrm{op}}.\mathrm{form}
\end{aligned}

\{\, \mathrm{Im}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vd)=\mathrm{Out}_{\mathrm{SEW},\mathrm{LMUL}}(\mathrm{Im}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vd),\lambda i.\pi_1(f(i)),vl,vstart,\mathrm{vm},\mathrm{V}_0,vta,vma),\ vstart=0,\ mstatus.VS=\mathrm{Dirty}(3),\ mstatus.FS=\mathrm{Dirty}(3),\ \mathrm{fcsr.fflags}\mathrel{|}=\bigcup_{i\in\mathrm{Act}(vl,vstart,\mathrm{vm},\mathrm{V}_0)}\pi_2(f(i)),\ \mathrm{exception}=\varnothing \,\}
