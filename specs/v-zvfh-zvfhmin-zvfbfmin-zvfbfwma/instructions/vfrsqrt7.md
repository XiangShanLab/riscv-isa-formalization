# VFRSQRT7 — vector floating-point reciprocal square-root estimate

`VFRSQRT7.V` returns the 7-bit estimate of $1/\sqrt{x}$ defined in §9.3 for each `SEW`-wide element
of `vs2` (Unpriv. §31.13.9, `sources/riscv-unprivileged.txt:18505-18625`). With `a_i` the element
`i` of `vs2`, the per-element result is $f(i)=\mathrm{rsqrt7}_{\mathrm{SEW}}(a_i)$, which carries the
class table and the lookup table of §9.3 and depends on no rounding mode.

**(VFRSQRT7.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{instr}=\mathrm{VFRSQRT7}.\mathrm{V})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$
