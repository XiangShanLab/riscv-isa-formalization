# FCVT.W, FCVT.WU, FCVT.L, FCVT.LU — floating-point to integer

`FCVT.T.F` converts $x=\mathrm{val}_F(a)$ to the integer type $T$ under the effective rounding mode. $\mathrm{ires}=\mathrm{roundInt}(x)$ is the rounded integer before range clamping; `W` is signed 32-bit, `WU` unsigned 32-bit, `L` signed 64-bit, `LU` unsigned 64-bit. A NaN or an out-of-range value saturates to the range limit and sets `NV(4)`; an in-range value that differs from $x$ sets `NX(0)` and an exact one sets no flag. $\min T$ and $\max T$ are the smallest and largest values of $T$ (Table 27 of the manual). `L` and `LU` require `XLEN=64`. Formats H, S, D, Q; the extension condition is `impl(Ext(F))`.

Within each block $T$ is the integer type named by the mnemonic: the `FCVT.W` blocks have $T=W$,
the `FCVT.WU` blocks $T=WU$, and likewise for `L` and `LU`. The right-hand side writes
$\mathrm{enc}_T(u)$, which sign-extends a 32-bit result to `XLEN` for both `W` and `WU` when
`XLEN=64` (Unpriv. §21.7, `sources/riscv-unprivileged.txt:7104-7112`).

The `exception` field of every block below lists only the exceptions the instruction itself can raise, and reads `\mathrm{exception}=\varnothing` when it raises none; the instruction-fetch outcomes depend only on the fetch address and are stated once in the README, not repeated here.

**(FCVT.W.0) Extension unavailable or effective FS Off → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(\mathrm{Ext}(F))\ \lor\ mstatus.FS=\mathrm{Off}(0)\bigr)\\
&\land\ (F\in\{\mathrm{H},\mathrm{S},\mathrm{D},\mathrm{Q}\})\\
&\land\ (\mathrm{instr}=\mathrm{FCVT.W}.F)\\
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$

**(FCVT.W.1) No H, M/S/U: the source is not correctly NaN-boxed → $\max T$, set NV(4)**

$$
\begin{aligned}
&\neg\mathrm{impl}(H)\ \land\ \mathrm{Priv}\in\{\mathrm{M},\mathrm{S},\mathrm{U}\}\\
&\land\ \mathrm{impl}(\mathrm{Ext}(F))\\
&\land\ (mstatus.FS\in\{\mathrm{Initial}(1),\mathrm{Clean}(2),\mathrm{Dirty}(3)\})\\
&\land\ \big(\mathrm{instr}.rm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\}\lor(\mathrm{instr}.rm=\mathrm{DYN}(7)\land fcsr.frm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\})\big)\\

&\land\ (F\in\{\mathrm{H},\mathrm{S},\mathrm{D},\mathrm{Q}\})\\

\end{aligned}
\longrightarrow
\{\, rd=\max T,\ mstatus.FS=\mathrm{Dirty}(3),\ \mathrm{fcsr.fflags}\mathrel{|}=\{\mathrm{NV}(4)\},\ \mathrm{exception}=\varnothing \,\}
$$
