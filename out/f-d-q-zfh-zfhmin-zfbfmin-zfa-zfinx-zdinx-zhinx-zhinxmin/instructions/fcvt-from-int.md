# FCVT.F.W, FCVT.F.WU, FCVT.F.L, FCVT.F.LU — integer to floating-point

`FCVT.F.T` converts the integer $u$ to format $F$ under the effective rounding mode, where $u$ is read from `rs1` as a value of type `T`: $u=\mathrm{sext}_n(x[\mathrm{rs1}][n-1:0])$ for the signed types `W` and `L`, $u=\mathrm{zext}_n(x[\mathrm{rs1}][n-1:0])$ for the unsigned types `WU` and `LU`, with $n=32$ for `W`/`WU` and $n=64$ for `L`/`LU` (Unpriv. §21.7, `sources/riscv-unprivileged.txt:7107-7113`). The conversion is exact when $\mathrm{rounded}=u$ and inexact otherwise, which sets `NX(0)`. Overflow is reachable only for `F=H`, so the overflow formulas are vacuous for S, D, and Q. A `WU` or `LU` source is non-negative, so only the positive-overflow formulas exist for them. `L` and `LU` require `XLEN=64`. Formats H, S, D, Q; the extension condition is `impl(Ext(F))`.

The `exception` field of every block below lists only the exceptions the instruction itself can raise, and reads `\mathrm{exception}=\varnothing` when it raises none; the instruction-fetch outcomes depend only on the fetch address and are stated once in the README, not repeated here.

**(FCVT.W.0) Extension unavailable or effective FS Off → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(\mathrm{Ext}(F))\ \lor\ mstatus.FS=\mathrm{Off}(0)\bigr)\\
&\land\ (F\in\{\mathrm{H},\mathrm{S},\mathrm{D},\mathrm{Q}\})\\
&\land\ (\mathrm{instr}=\mathrm{FCVT}.F.\mathrm{W})\\
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$

**(FCVT.W.1) No H, M/S/U: exact, no overflow**

$$
\begin{aligned}
&\neg\mathrm{impl}(H)\ \land\ \mathrm{Priv}\in\{\mathrm{M},\mathrm{S},\mathrm{U}\}\\
&\land\ \mathrm{impl}(\mathrm{Ext}(F))\\
&\land\ (mstatus.FS\in\{\mathrm{Initial}(1),\mathrm{Clean}(2),\mathrm{Dirty}(3)\})\\
&\land\ \big(\mathrm{instr}.rm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\}\lor(\mathrm{instr}.rm=\mathrm{DYN}(7)\land fcsr.frm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\})\big)\\
&\land\ (u=\mathrm{sext}_{32}(x[rs1][31:0]))\\
&\land\ (\mathrm{rounded}=u)\\
&\land\ \neg\big(\lvert\mathrm{rounded}\rvert\ge2^{E_{\max}+1}\big)\\
&\land\ (F\in\{\mathrm{H},\mathrm{S},\mathrm{D},\mathrm{Q}\})\\
&\land\ (\mathrm{instr}=\mathrm{FCVT}.F.\mathrm{W})\\
\end{aligned}
\longrightarrow
\{\, fd=\mathrm{enc}_F(u),\ mstatus.FS=\mathrm{Dirty}(3),\ \mathrm{exception}=\varnothing \,\}
$$
