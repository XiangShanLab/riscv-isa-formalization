# VFWMACC, VFWNMACC, VFWMSAC, VFWNMSAC — vector widening floating-point fused multiply-accumulate

The four instructions multiply two `SEW`-wide elements and accumulate into a `2·SEW`-wide
destination element (Unpriv. §31.13.7, `sources/riscv-unprivileged.txt:18460-18495`). The
multiplicands are `vs1` and `vs2`; the addend is the old `vd`. Write
`op∈{MACC,NMACC,MSAC,NMSAC}` for the mnemonic. With `a_i` element `i` of `vs1`, `b_i` element `i`
of `vs2` for `.vv` or $\mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])$ for `.vf`, and `c_i` the old element
`i` of `vd` at `2·SEW` bits, the element equations are those of the single-width VFMACC table with
`fma` taken at `2·SEW` and with both multiplicands widened:

| `op` | `f(i)` |
|---|---|
| `MACC` | $\mathrm{fma}_{2\mathrm{SEW}}(\mathrm{widen}(a_i),\mathrm{widen}(b_i),c_i)$ |
| `NMACC` | $\mathrm{fma}_{2\mathrm{SEW}}(\mathrm{neg}(\mathrm{widen}(a_i)),\mathrm{widen}(b_i),\mathrm{neg}(c_i))$ |
| `MSAC` | $\mathrm{fma}_{2\mathrm{SEW}}(\mathrm{widen}(a_i),\mathrm{widen}(b_i),\mathrm{neg}(c_i))$ |
| `NMSAC` | $\mathrm{fma}_{2\mathrm{SEW}}(\mathrm{neg}(\mathrm{widen}(a_i)),\mathrm{widen}(b_i),c_i)$ |

The destination has `EEW=2·SEW` and `EMUL=2·LMUL`, so `LMUL=8` is reserved.

**(VFWMACC.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{op}\in\{\mathrm{MACC},\mathrm{NMACC},\mathrm{MSAC},\mathrm{NMSAC}\})\\
&\land\ (\mathrm{form}\in\{\mathrm{VV},\mathrm{VF}\})\\
&\land\ (\mathrm{instr}=\mathrm{VFW}_{\mathrm{op}}.\mathrm{form})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$
