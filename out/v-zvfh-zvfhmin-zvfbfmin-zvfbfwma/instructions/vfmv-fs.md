# VFMV.F.S — vector floating-point move, vector element to scalar

`VFMV.F.S` copies element 0 of `vs2` into the scalar `f[rd]` (Unpriv. §31.16.2,
`sources/riscv-unprivileged.txt:20010-20033`). The instruction ignores `LMUL` and register groups:
it reads one element from the single register `vs2`, and it is encoded with `vm=1`; the masked
encoding is reserved (§4.5). It performs its operation even when `vstart\ge vl` or `vl=0`, so the
formula carries no `vl` conjunct and always writes `f[rd]`. The value is placed in the
`\mathrm{box}_{\mathrm{SEW}}` position of the register, which is the identity when
`\mathrm{FLEN}=\mathrm{SEW}`.

**(VFMV.F.S.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{instr}=\mathrm{VFMV}.\mathrm{F}.\mathrm{S})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$

**(VFMV.F.S.1) No H, M/S/U: scalar extraction**

$$
\begin{aligned}
&\neg\mathrm{impl}(H)\ \land\ \mathrm{Priv}\in\{\mathrm{M},\mathrm{S},\mathrm{U}\}\\
&\land\ \bigl(\mathrm{impl}(V)\ \land\ (\mathrm{SEW}=16\Rightarrow\mathrm{impl}(Zvfh))\ \land\ (\mathrm{SEW}=32\Rightarrow\mathrm{impl}(F))\ \land\ (\mathrm{SEW}=64\Rightarrow\mathrm{impl}(D))\bigr)\\
&\land\ mstatus.VS\in\{\mathrm{Initial}(1),\mathrm{Clean}(2),\mathrm{Dirty}(3)\}\\
&\land\ mstatus.FS\in\{\mathrm{Initial}(1),\mathrm{Clean}(2),\mathrm{Dirty}(3)\}\\
&\land\ fcsr.frm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\}\\
&\land\ \mathrm{SEW}\in\{16,32,64\}\\
&\land\ \mathrm{vm}=1\\
&\land\ \mathrm{instr}=\mathrm{VFMV}.\mathrm{F}.\mathrm{S}
\end{aligned}
\longrightarrow
\{\, f[rd]=\mathrm{box}_{\mathrm{SEW}}\bigl(\mathrm{el}^{\mathrm{SEW}}_{1}(vs2,0)\bigr),\ vstart=0,\ mstatus.VS=\mathrm{Dirty}(3),\ mstatus.FS=\mathrm{Dirty}(3),\ \mathrm{exception}=\varnothing \,\}
$$
