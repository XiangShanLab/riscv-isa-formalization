# VFSLIDE1UP.VF — vector floating-point slide-1-up

`VFSLIDE1UP.VF` copies the scalar `f[rs1]` into element 0 and shifts the elements of `vs2` up by
one index: element `i` receives `vs2[i-1]` for `\max(vstart,1)\le i<vl` (Unpriv. §31.16.3.4,
`sources/riscv-unprivileged.txt:20136-20166`). Element 0 is written only when it is active, that is
when `vstart=0`; with `vstart>0` the scalar is not written and elements below `vstart` are unchanged.
The instruction is masked; an element whose mask bit is zero keeps its value or becomes agnostic
under `vma`, and elements from `vl` on follow `vta`. If `vstart\ge vl` the destination is unchanged.
The destination group must not overlap the source group; other overlaps are reserved (§4.5).

With `a_i` element `i` of `vs2`, the per-element result is $f(i)=\mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])$
for `i=0` and $f(i)=a_{i-1}$ otherwise. No flag is raised and no `f` register is written.

**(VFSLIDE1UP.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{instr}=\mathrm{VFSLIDE1UP}.\mathrm{VF})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$

**(VFSLIDE1UP.1) No H, M/S/U: slide up by one with a scalar fill**

$$
\begin{aligned}
&\neg\mathrm{impl}(H)\ \land\ \mathrm{Priv}\in\{\mathrm{M},\mathrm{S},\mathrm{U}\}\\
&\land\ \bigl(\mathrm{impl}(V)\ \land\ (\mathrm{SEW}=16\Rightarrow\mathrm{impl}(Zvfh))\ \land\ (\mathrm{SEW}=32\Rightarrow\mathrm{impl}(F))\ \land\ (\mathrm{SEW}=64\Rightarrow\mathrm{impl}(D))\bigr)\\
&\land\ mstatus.VS\in\{\mathrm{Initial}(1),\mathrm{Clean}(2),\mathrm{Dirty}(3)\}\\
&\land\ mstatus.FS\in\{\mathrm{Initial}(1),\mathrm{Clean}(2),\mathrm{Dirty}(3)\}\\
&\land\ fcsr.frm\in\{\mathrm{RNE}(0),\mathrm{RTZ}(1),\mathrm{RDN}(2),\mathrm{RUP}(3),\mathrm{RMM}(4)\}\\
&\land\ \mathrm{SEW}\in\{16,32,64\}\\
&\land\ \mathrm{instr}=\mathrm{VFSLIDE1UP}.\mathrm{VF}
\end{aligned}
\longrightarrow
\{\, \mathrm{Im}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vd)=\mathrm{Out}_{\mathrm{SEW},\mathrm{LMUL}}(\mathrm{Im}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vd),\lambda i.\bigl(i=0\ ?\ \mathrm{fsrc}_{\mathrm{SEW}}(f[rs1])\ :\ \mathrm{el}^{\mathrm{SEW}}_{\mathrm{LMUL}}(vs2,i-1)\bigr),vl,vstart,\mathrm{vm},\mathrm{V}_0,vta,vma),\ vstart=0,\ mstatus.VS=\mathrm{Dirty}(3),\ \mathrm{exception}=\varnothing \,\}
$$
