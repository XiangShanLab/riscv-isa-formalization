# VFCVT — vector floating-point/integer type-convert, same width

The six forms convert between `SEW`-wide floating-point elements and `SEW`-wide integer elements
with the rules of §8.1 and §8.2 (Unpriv. §31.13.17, `sources/riscv-unprivileged.txt:19173-19240`).
`f2i` forms write the two's-complement or unsigned integer encoding of the converted value, and
`i2f` forms read the element as an integer. The `.rtz` forms round towards zero; the other `f2i`
forms use `fcsr.frm`. Saturation and `NV(4)` for an out-of-range conversion, and `NX(0)` for an
inexact one, follow §8.1. The `i2f` forms raise only `NX(0)` or `OF(2)`.

**(VFCVT.0) Extension unavailable, vector or floating-point state Off, or `vill=1` → only IllegalInstruction(2)**

$$
\begin{aligned}
&\bigl(\bigl(\mathrm{Priv}\in\{\mathrm{VS},\mathrm{VU}\}\land(vsstatus.VS=\mathrm{Off}(0)\lor sstatus.VS=\mathrm{Off}(0)\lor vsstatus.FS=\mathrm{Off}(0)\lor sstatus.FS=\mathrm{Off}(0))\bigr)\\
&\qquad\lor\ \neg\mathrm{impl}(V)\ \lor\ (\mathrm{SEW}=16\ \land\ \neg\mathrm{impl}(Zvfh))\ \lor\ (\mathrm{SEW}=32\ \land\ \neg\mathrm{impl}(F))\ \lor\ (\mathrm{SEW}=64\ \land\ \neg\mathrm{impl}(D))\ \lor\ mstatus.VS=\mathrm{Off}(0)\ \lor\ mstatus.FS=\mathrm{Off}(0)\ \lor\ vill=1\bigr)\\
&\land\ (\mathrm{SEW}\in\{16,32,64\})\\
&\land\ (\mathrm{op}\in\{\mathrm{XU.F},\mathrm{X.F},\mathrm{RTZ.XU.F},\mathrm{RTZ.X.F},\mathrm{F.XU},\mathrm{F.X}\})\\
&\land\ (\mathrm{instr}=\mathrm{VFCVT}.\mathrm{op}.\mathrm{V})
\end{aligned}
\longrightarrow
\{\, \mathrm{exception}=\{\mathrm{IllegalInstruction}(2)\} \,\}
$$
